# RemoteTap — Python dependencies
#
# RUNTIME
#   The backend intentionally has no third-party runtime dependencies.
#   It is built on the Python 3 standard library only:
#     asyncio, socket, json, dataclasses, enum, logging, secrets, argparse
#   Deliberate choices for the prototype:
#     - No web framework for the *device service*: its transport is raw TCP/UDP,
#       not HTTP. (The separate local demo bridge does use one; see below.)
#     - No cloud SDK: RemoteTap talks to the device over Tailscale directly.
#     - No GPIO library yet: the actuator is simulated at this stage.
#
#   Tailscale itself is a system-level client, not a Python package, so it is
#   not listed here.
#
# WEB BRIDGE (browser demonstration interface)
#   A browser cannot open a raw TCP or UDP socket, so a small local bridge
#   process is needed between the page and the device service. It speaks the
#   existing TCP command protocol as a client and is the sole UDP listener, then
#   exposes both to the page over localhost HTTP + WebSocket.
#   The bridge is a *demo* front end; the device service above still uses only
#   the standard library.
fastapi>=0.110
uvicorn[standard]>=0.29

# DEVELOPMENT / TESTING
pytest>=8.0
pytest-asyncio>=0.24
# Async HTTP + WebSocket clients used by the bridge tests.
httpx>=0.27
websockets>=12.0
